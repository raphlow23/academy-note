수봉화실 개인정보 안내

수봉화실는 개인용 수강생·수강권·예약 관리 도구입니다.

로그인과 저장

Google 계정 이메일을 확인하고, 앱이 만들거나 사용자가 직접 선택한 Google Drive 파일에 접근하는 권한을 요청합니다. 수강생 이름·연락처·납부·예약 내용은 로그인한 사용자가 소유하거나 수정 권한을 받은 Google 시트에 저장됩니다. 이 자료는 GitHub 저장소에 올리지 않습니다.

공유

자료는 기본 비공개입니다. 소유자가 공유 설정에서 특정 Google 이메일에 권한을 허용하면 해당 계정도 전체 자료를 읽고 수정할 수 있습니다. Google 시트를 직접 공유하면 그 권한도 적용됩니다.

기기 보관

조회한 자료는 사용 중 메모리에만 유지합니다. 로그인 유지를 위해 Google 액세스 토큰과 만료 시각을 이 기기의 브라우저 저장소와 현재 탭에 보관하며, 다시 실행할 때 Google에 계정을 재확인합니다. 유효기간이 끝나거나 로그아웃·계정 전환을 하면 연결 정보를 지웁니다. 브라우저 저장소에는 연결 정보와 계정별 선택한 파일 ID를 보관하며, 만료된 권한을 연장하지 않습니다. 로그아웃·계정 전환 시 화면의 이전 계정 자료와 토큰을 비웁니다. 사용자가 내려받은 엑셀·CSV·JSON·열람본에는 개인정보가 포함될 수 있으므로 직접 안전하게 보관해야 합니다.

삭제·연결 해제

Google 계정의 타사 연결 관리에서 앱 권한을 철회할 수 있습니다. 자료 파일은 본인의 Google Drive에서 관리합니다. 앱 사용 종료·권한 철회가 이미 내려받거나 공유한 복사본까지 삭제하지는 않습니다.

외부 서비스

화면 제공에는 GitHub Pages를, 로그인·파일 저장에는 Google Identity Services와 Google Drive/Sheets를 사용합니다. 각 서비스의 개인정보 처리 및 이용 조건도 적용됩니다.
