요일을 선택하고 시작·종료를 30분 단위로 정하세요. 선택한 요일에 같은 타임을 한 번에 추가할 수 있습니다.

정규권은 타임 전체를 예약합니다. 1일 클래스는 타임 안에서 30분·1시간 등 수강 길이를 정할 수 있습니다. 수업 길이와 관계없이 예약 1건은 1회 차감됩니다.

앱 없이도 열 수 있는 원본

웹앱과 별개인 구글 시트 파일입니다. 수강현황 탭에서 현재 잔여·누적 수강·누적 납부를 앱 없이 확인할 수 있어요. 주소를 별도 즐겨찾기에 보관하세요.

원본 구글 시트 ↗엑셀(.xlsx) 다운로드

직접 내려받기: 시트의 파일 → 다운로드 → Microsoft Excel(.xlsx). 모든 탭을 한 파일로 보관합니다.

인터넷이 안 돼도 조회 · 출력

오프라인 열람본은 모든 수강생의 잔여·누적·납부 요약과 전체 원본 표를 담은 HTML 파일입니다. PC에서 인터넷 없이 열고 인쇄할 수 있어요.

내려받은 시점의 복사본입니다. 새 기록은 자동 반영되지 않습니다. 전체 JSON은 이관용 원본이며 앱 내 자동 복원 기능은 없습니다.

전체 기간 CSV 내보내기

화면의 날짜·검색 조건과 관계없이 전체 기록을 내보냅니다. CSV는 엑셀에서 열 수 있습니다.

웹앱이 열리지 않을 때

앱 장애: 원본 시트를 직접 열어 조회·다운로드·인쇄.
구글 접속 장애: PC에 미리 보관한 엑셀 또는 오프라인 열람본을 열어 조회·출력.

매주, 중요한 변경 후 백업하세요. 원본 시트는 보존되지만 시트나 계정을 삭제하면 접근할 수 없습니다. 자동 PC 백업은 포함되지 않습니다.

사용설명서 PDF

최신 웹화면을 넣은 14쪽 설명서입니다. 수강생·수강권·첫 예약 통합 등록, 자동 완료와 취소, 시간표·휴무·공유·백업 방법을 안내합니다.

내 자료 공유하기

지정한 구글 계정에만 권한을 부여합니다. 링크만 아는 사람은 접근할 수 없습니다. 알림 메일은 자동 발송하지 않습니다.

공유받은 자료 연결

소유자가 내 구글 계정에 수정 권한을 준 뒤 전달한 공유 주소를 붙여 넣으세요. 연결해도 내 개인 자료와 합쳐지지 않습니다.

공유받은 자료는 소유자의 구글 시트에 저장합니다. 본인 자료는 언제든 상단 ‘현재 자료’에서 다시 선택할 수 있습니다.

수강권 · 납부 등록

1일클래스는 1회, 추가납부는 0회입니다. 금액에는 실제 받은 금액만 입력하세요. 저장된 거래는 이 화면에서 수정·삭제할 수 없으므로 확인 후 등록하세요.

새 예약

확정하면 1회 차감됩니다. 휴무일이나 잔여 횟수가 없는 수강권은 예약할 수 없습니다.

앱 버전

다른 계정에서 403·접근 차단이 나타날 때

계정 선택 버튼에서 원하는 구글 계정을 선택하세요. 파일 접근이 차단되면 구글 파일 선택으로 직접 연결하거나 소유자의 공유 허용을 확인하세요.

새 계정은 로그인 후 저장 공간이 자동으로 준비됩니다. 그래도 차단되면 오류 화면의 자세한 문구를 확인해야 합니다. 조직 계정은 관리자가 앱을 제한할 수도 있습니다.
